Editable table view prototypes

Three different ways to make an RMS table more spreadsheet-like: paste rows in from Excel/CSV/JSON, insert them one-by-one or in a batch, and copy or export back out. All three operate on the same sample table below - nothing here touches real Users/Resources/Capabilities data. Try each, then decide (if any) which is worth building into the real Admin/Planner tables.

Sample files for testing paste/import: sample-items.csv · sample-items.json · sample-items.xlsx — open the .xlsx in Excel/Sheets and copy a range of cells to test the Excel-paste path, or open the .csv/.json directly, or use each page's own "Import file" control.
📋 Option A — Spreadsheet grid 📥 Option B — Form table + bulk import ⌨️ Option C — Custom keyboard grid
Option A — Spreadsheet-like grid
Every cell is directly editable in place, like a plain spreadsheet.

Click any cell and type, or paste a block copied from Excel/Sheets/a CSV starting at any cell - it fills right and down, adding rows if the paste is bigger than the table. One "Save all" button replaces the whole sandbox table with whatever's currently in the grid. Closest to "just paste into Excel and it works", but has no undo and no explicit per-row actions.

Option B — Traditional form table + bulk import panel
The exact editing style RMS already uses everywhere else (Users, Resources, Capabilities…), plus a bulk-import add-on.

Each row has its own Save/Delete, exactly like every other table in this app. A separate "Bulk add rows" panel accepts a paste or a file upload, shows a preview of what will be inserted, and adds them as new rows in one batch on confirmation - existing rows are never touched by an import. Closest to "the smallest change to what RMS already does".

Open Option B →
Option C — Custom keyboard-navigable grid
A hand-built data grid: arrow keys/Tab to move, click-and-shift-click to select a range, right where you'd expect in a real spreadsheet.

Select a rectangular range with the mouse or keyboard, paste to fill exactly that shape (not just from row 1), copy a selection back out as a tab-separated block for pasting into Excel, and use the toolbar to add/delete rows. The most "feels like a real spreadsheet" of the three, and the most custom code behind it.
