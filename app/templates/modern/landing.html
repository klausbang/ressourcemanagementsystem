Resource Management System

Plan, allocate, and report on test lab work — in one place

RMS replaces spreadsheets for test planning: manage resources and capabilities, allocate them to customer orders, and let technicians run and report on the tests — all from the same data.

Log in to get started

👤 Three roles, one system

  • RMS Administrator: manages resources, capabilities, and user accounts.
  • Test Planner: manages customer orders and EUTs, plans test activities, and assigns resources to them.
  • Test Technician: runs the tests assigned to them and fills in, submits, and reviews test reports.

Log in with just a username — this is a demonstrator with no passwords. The login page lists a demo account for each role.
