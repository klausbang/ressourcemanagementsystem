RMS

Resource Management System

Plan tests, allocate resources, execute work orders, and issue signed-off test reports — end to end.

From customer order
to approved test report,
in one system.

RMS is a lightweight, web-based system for test labs and service providers: it tracks every resource you test with — equipment, facilities, procedures, and technicians — and carries a customer's order all the way through planning, execution, and a reviewed, printable test report.

What RMS Does

🗂️

Resource & Capability Catalog

Register equipment, facilities, procedures, and technicians; tag each with the capabilities it can perform.

🧾

Customer Orders & Ordered Tests

Capture each customer order and the specific tests requested under it, with the capability each test requires.

🔧

Multi-Resource Allocation

Assign equipment, facility, and technician together to one test — only capability-matched resources are offered.

🧰

Technician Work Orders

Each technician sees exactly the tests assigned to them and runs a work order through planned → in progress → completed.

📋

Test Procedure Library

Documented processes with required equipment/facility, safety notes, and a structured checklist of expected values.

📄

Digital Test Reports

Auto-generated, fillable report per work order — actual values, pass/fail, unit serial number, notes — signed and reviewed.

✅

Review & Approval

A second technician or a planner approves or rejects every report before it's final — full accountability, no self-sign-off.

🖨️

Print-Ready A4 Reports

Every report doubles as a clean A4 page — printable blank during the test, or complete and signed afterward.

🖥️

Two Interfaces, One System

A plain zero-dependency view and a modern styled view render the exact same data — switch anytime.

How It Works

1

Set Up

Admin registers resources, capabilities, and users.

2

Plan

Planner logs the order and allocates matching resources to each test.

3

Execute

Technician runs the work order and fills in the generated test report.

4

Approve

A peer or planner reviews the report and signs it off — or sends it back.

Built for Every Role

RMS Administrator

Owns the master data: resources, capabilities, user accounts and their access.

Test Planner

Owns customer orders and matches the right resources to every requested test.

Test Technician

Owns execution: work orders, test procedures, and the signed test report.

Why Teams Choose RMS

  • One record per order — no spreadsheets, no email threads to reconstruct what was tested.
  • Nothing gets assigned without the right capability — validated automatically.
  • Every test report carries an audit trail: who tested it, who reviewed it, when.
  • Referential integrity is enforced — you can't silently orphan a report or an order.
  • Runs locally today; the same design migrates cleanly to cloud hosting tomorrow.

Under the Hood

Built with Python + Flask, running on SQLite locally with a clear migration path to a managed PostgreSQL deployment. No proprietary lock-in, no external services required to run it.
