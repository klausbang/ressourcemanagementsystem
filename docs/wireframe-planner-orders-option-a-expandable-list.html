Wireframe: Planner Orders — Option A: Expandable List

Role focus: Test Planner

← Back to Customer Order Data Overview · Documentation Home

Purpose

Keep every order in one flat, scannable list — sortable/filterable like today's table — but let the planner expand any row in place to see its EUTs and test activities, without navigating to a separate tab or page. Best when a planner mostly scans many orders and only occasionally needs to drill into one.

Wireframe only: dummy data, no working links or forms. The ▶/▼ rows below are real expand/collapse (no JavaScript needed) so you can try the interaction; everything inside them is static.

Trade-offs

  • Good for: scanning many orders at once; keeping the whole-portfolio status visible while still being able to drill in without losing your place in the list.
  • Weaker at: a heavily-loaded order (like ORD-2026-004 with 17 activities) makes for a long expanded block that pushes other rows far down the page; no room for a persistent "always visible" detail pane.
