1. Purpose

A single reference table listing every distinct page in RMS and what it does, for anyone getting oriented in the system without reading the SRS or the code. Requested directly by a proposal filed from the Admin page (id 19), and kept current since - most recently for the Phase 27 Proposals Table view. Two pages - Admin Manage and Planner Orders - are internally tabbed, so section 3 breaks each of those pages' tabs out individually, since that's where the real functional differences live.

Column definitions used throughout: View-only or editable means whether the page has any form that writes data (a filter form doesn't count). Function buttons lists the distinct actions available, not every button instance. Sortable means the page's table(s) have clickable, server-side sortable column headers (app/table_utils.py:rows_with_meta). UI mode notes where a page differs from the norm - most pages exist in both Simple (plain HTML, no JS) and Modern (styled, JS-enabled) interfaces over identical routes and data (see Dual Interface: Simple and Modern); a few (Technician Dashboard, Test Reports) exist only in Modern.
