Purpose

A slim, always-visible order list on the left; the full picture of whichever order is selected on the right — EUTs, activities, allocations, milestones, visits, weekly note, and any conflict, all in one screen, without tab-switching. Best for a planner doing sustained work on one order at a time (e.g. building out a new order's activities and assignments in one sitting), at the cost of portfolio-wide overview.

Wireframe only: dummy data; the left list shows ORD-2026-003 selected (highlighted) with its detail on the right, to demonstrate the pattern for the order that has the most going on (conflict + waiting-for-customer + multiple activities).

Trade-offs

  • Good for: deep, uninterrupted work on one order — every fact about it is on screen at once, with no tab-switching between "Ordered tests" and "Resource assignment" like the current layout requires.
  • Weaker at: the left list only has room for a status dot and name per order, so it can't replace the portfolio-wide view Option B gives; a planner managing many orders in parallel would likely still want a Kanban/board landing screen (Option B) that opens into this detail view.
