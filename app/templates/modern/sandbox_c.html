Prototype · Option C

Custom keyboard-navigable grid

Arrow keys/Tab/Enter move the active cell. Click a cell, then Shift+click (or Shift+arrow) another to select a rectangle. Click a row handle (left column) or a column header to select a whole row/column; click the top-left corner to select everything. Ctrl+C/Ctrl+X/Ctrl+V and Ctrl+Z (undo) all work as expected. Click 🔍 to filter (supports */? wildcards and | for OR, e.g. INV-* | EQP-*). Select 2+ rows, click ✏️, edit the first one, then Ctrl+R to repeat those changes on the rest.
